# On-Screen Indicator Position

Windhawk mod that puts the Windows 11 volume, brightness and camera indicator anywhere on the screen, instead of the three spots Windows offers.

Install it from the catalog at [windhawk.net/mods/on-screen-indicator-position](https://windhawk.net/mods/on-screen-indicator-position). The copy Windhawk installs lives in [ramensoftware/windhawk-mods](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/on-screen-indicator-position.wh.cpp), this one tracks it.

Bugs and feature requests go in [issues](https://github.com/mario0318/on-screen-indicator-position/issues) here.
